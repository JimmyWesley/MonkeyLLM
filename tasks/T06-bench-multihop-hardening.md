# T06 — Monkey Bench: multi-hop question hardening

status: DONE (2026-06-11) — results below; criterion decision handed to T01
depends-on: T01 (motivating data)

## Goal

Make the bench question set actually multi-hop (>= 3 hops) and deep enough to
exercise the economics the Phase 1 token criterion measures — and to make
shouts (shortcut grafting) fire at all.

## Context

T01 measured: monkey 18/18 precision 1.0, but monkey/iter token ratio ~1.23x —
the <= 60% criterion assumes questions where flat retrieval wanders. In
questions-v2, ~80% resolve in 1-2 hops, so one vector search is enough for the
iter baseline. The roadmap flagged exactly this risk ("bench questions too
trivial / literal summary matches"). Separately, 28 hunts on forests/forest-fixture
produced zero shouts (threshold >= 4 hops never reached) — same root cause.

## Steps

1. Extend `forests/scripts/build_bench_forest.py` with deep chains: facts reachable
   only by composing 3+ nodes (A mentions B, B's body points to C, answer in
   C's dataset row), buried facts in >4k-token bodies, and cross-branch trails.
2. Author a `questions-v3.json` tier: each question annotated with
   `min_hops` ground truth; include buried-fact questions (sniff tier) and
   dataset-join questions (query tier).
3. Re-run T01 step 5 on v3; re-evaluate the token criterion on the
   `min_hops >= 3` subset.
4. Verify shouts fire: with `--learn`, expect > 0 shortcut grafts on v3;
   measure pass-2 hop reduction (feeds the Phase 2 convergence curve).

## Acceptance criteria

- [x] >= 50% of v3 questions have min_hops >= 3 — **100%** (11/11; chains
      release→project→lead→city, recall-lote→product→owner, contract→product→
      owner, dataset-join→product→owner, generated by `build_questions_v3` in
      forests/scripts/build_bench_forest.py with paraphrased anchors)
- [x] token criterion re-measured and reported — raw median ratio 1.04 (fails
      as written); tokens-per-correct-answer 0.58 ✓ (monkey 11/11 vs iter
      7/11). Full numbers + pending criterion decision recorded in T01.
- [x] at least one shout fires per --learn pass on v3 — **4 shortcut grafts**
      in pass 1 (e.g. release-plataforma-tambor → wanda-guimarães). Required
      a real fix, spec'd as **v0.6**: the trigger used hops-to-banana
      (look+move only), blind to pick chains — 39 hunts had produced zero
      shouts. New `trail_len` metric (read calls before the first answer-node
      harvest) drives the shout. Pass 2 on the learned forest: shortcut-covered
      v3-09 dropped 1557→1243 tokens (-20%), 8/11 questions same-or-cheaper,
      total -4.8% — first point of the Phase 2 convergence curve.
- [x] iter baseline regrades correctly on v3 (per-question traces inspected;
      topk's 0/11 is genuine — it finds chain link 1 and answers "context
      does not say")

## Out of scope

Changing primitive contracts or budgets to game the metric; touching v1/v2
sets (keep them for longitudinal comparison).
